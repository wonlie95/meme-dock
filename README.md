# MemeDock

Windows 本地表情包管理与发送工具。按 **Ctrl + Shift + Space** 显示或隐藏面板。

## 使用

```powershell
npm install
npm start
```

- 点击“导入表情”批量加入 PNG、JPG、GIF、WebP、BMP 图片或 QQ `.eif` 表情包。EIF 会按 QQ 容器内的原始分组拆分为多个本地分类；部分旧包仅保留数字分组 ID，分类会显示为“QQ 分组 N”。
- 输入名称或标签（如“笑”）即时搜索；右键某个表情即可改名称、分类和多个标签。
- 点击右上角 ⚙ 可新增、重命名或删除自定义分组；重命名会同步调整本地分类文件夹。 “全部”为总览，“常用”为删除分组时的保底接收分组，因此这两个系统分组不能重命名或删除。
- 进入某个具体分组并清空搜索框后，可直接拖动缩略图调整表情顺序；排序会保存到本地。
- 点击缩略图后，软件会把图片写入剪贴板、隐藏面板并发送 `Ctrl+V` 到先前窗口。
- 程序关闭窗口后会留在右下角系统托盘；单击托盘图标打开，右键图标可退出。
- GIF 与其他图片会以图片剪贴板格式粘贴，QQ 会将其作为聊天图片而非“上传文件”。

数据及导入的图片保存在 Electron 的用户数据目录，不会修改原始图片。每个分类会自动建立一个同名文件夹；调整表情分类时，已导入的图片也会自动移动到对应文件夹。

> 某些以管理员身份运行的目标软件会阻止普通权限程序模拟按键；此时图片已经在剪贴板中，可手动 Ctrl+V，或以同等管理员权限启动 MemeDock。
